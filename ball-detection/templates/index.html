Project Overview

The Real-Time Ball Detection System is a high-performance computer vision application engineered to solve the challenges of monocular 2D ball tracking. Using lightweight YOLOv8 deep neural network models combined with OpenCV spatial processing and temporal filtering algorithms, the system delivers high accuracy, stable bounding boxes, and low-latency inference.

Core Technologies Used

Python 3.10/3.11 Ultralytics YOLOv8 OpenCV Vision Engine Flask / Express Node.js HTML5 Canvas & Web APIs Gemini 3.6 Flash AI

Evaluation Metrics & Mathematical Formulas

  • Precision (P): TP / (TP + FP) — Proportion of correct ball detections among all predictions.
  • Recall (R): TP / (TP + FN) — Proportion of true ground truth balls correctly detected.
  • F1 Score: 2 * (P * R) / (P + R) — Harmonic mean balancing accuracy and sensitivity.
  • Temporal EMA: S_t = α * Y_t + (1 - α) * S_{t-1} — Exponential Moving Average smoothing for zero box flicker.
